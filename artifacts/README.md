# Evidence artifacts

Stored measurement outputs are preserved here without changing their original
scores, predictions, timings or memory measurements. Headline measurements are
indexed in [`../docs/EVIDENCE.md`](../docs/EVIDENCE.md) and presented in
[`../docs/REPORT.md`](../docs/REPORT.md).

Historical diagnostics and negative results are also retained; they are not all
claims made by the current showcase. The conditions and limitations recorded in
each artifact still apply.

Implementation code, experiment scripts, training checkpoints and raw execution
logs are temporarily withheld pending publication. The files in this directory
are measurement outputs, not an installable implementation.
